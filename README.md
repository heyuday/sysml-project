# Agent SQL caching: CS5470 Team 19

This repo has two independent projects that share no code.

| Folder | What it is |
|---|---|
| [`agent-sql-bench/`](agent-sql-bench/) | **Main project.** A small benchmark for caching SQL results requested by concurrent LLM agents, built in short iterations. Start with its [README](agent-sql-bench/README.md) and [NOTES](agent-sql-bench/NOTES.md). |
| [`sysml-project/`](sysml-project/) | A separate, more extensive SQL-result-caching experiment by MadBonzz, copied unchanged from [MadBonzz/sysml-project](https://github.com/MadBonzz/sysml-project). It covers normalization, CDC invalidation, refresh and eviction on CH-benCHmark and BIRD. Its commands assume you run them from inside that folder. |
